# 🚀 스윙스타 (SWING STAR)

원버튼 브라우저 아케이드 게임. 행성 궤도를 빙글빙글 돌다가 한 번의 입력으로 발사해,
다음 행성의 궤도에 올라타며 우주로 올라갑니다.

**▶ [지금 바로 플레이](https://gyusun301-sys.github.io/swing-star/)**

## 조작

버튼은 하나뿐입니다.

| 입력 | 동작 |
|---|---|
| 클릭 · 터치 · `Space` · `Enter` | 발사 |
| `M` | 소리 켜기 / 끄기 |

행성 **정중앙**을 향해 지나가며 착지하면 `PERFECT` 판정이 나고, 연속으로 성공하면
점수 배율이 최대 5배까지 올라갑니다. 화면 밖으로 날아가면 게임 오버.

## 등장 요소

| | 이름 | 설명 |
|---|---|---|
| 🧊 | 얼음 행성 | 공전 속도가 절반 가까이 느려집니다 |
| 🌋 | 용암 행성 | 3초 안에 탈출하지 않으면 사망 |
| 🕳️ | 블랙홀 | 중력으로 비행 궤적이 휩니다 (속도는 일정) |
| ✦ | 별 조각 | 모아서 우주선 스킨을 해금 |

우주선 스킨 5종(기본 · 네온 · 선셋 · 무지개 · 골드)을 메뉴 상점에서 구매할 수 있고,
최고 기록·조각·보유 스킨은 `localStorage`에 저장됩니다.

## 실행

빌드도, 의존성도, 패키지 매니저도 없습니다. 파일 하나가 전부입니다.

```bash
git clone https://github.com/gyusun301-sys/swing-star.git
```

받은 뒤 `index.html`을 브라우저로 바로 열면 됩니다 (`file://`로도 동작합니다).

## 기술

- 순수 HTML + CSS + JavaScript, 외부 라이브러리 0개
- 렌더링: Canvas 2D (DPR 대응)
- 사운드: Web Audio API로 **실시간 합성** — 오디오 파일이 하나도 없습니다
- 햅틱: `navigator.vibrate`
- 대기 화면에서는 AI(`demoPilot()`)가 혼자 게임을 시연합니다
